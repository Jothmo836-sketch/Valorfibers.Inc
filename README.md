# Valorfibres Inc

A static marketing website for fibre, copper, and critical infrastructure solutions.

## Local development

```bash
npm install
npm run dev -- --host 0.0.0.0
```

Then open the local Vite URL in the browser.

## Production build

```bash
npm run build
```

## Deployment

This project is ready for deployment on Vercel using the default Vite settings:

- Build command: `npm run build`
- Output directory: `dist`
